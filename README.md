# 🤖 AI Rule-Based Chatbot (Python)

A simple **Rule-Based Chatbot** built using **Python**. This chatbot interacts with users using predefined rules and responds to greetings, questions, calculations, jokes, motivational quotes, date, time, and more.

---

## ✨ Features

- 👋 Greets the user
- 🤖 Introduces itself
- 😊 Responds to "How are you?"
- 🧑 Remembers the user's name
- 🕒 Displays the current time
- 📅 Displays the current date
- 😂 Tells random programming jokes
- 💡 Gives motivational quotes
- 🧮 Performs basic calculations
- 🙏 Responds to thanks
- 📖 Help command to show available features
- 👋 Exit using the `bye` command

---

## 🛠️ Technologies Used

- Python 3.x
- Built-in `random` module
- Built-in `datetime` module

## 💬 Available Commands

| Command | Description |
|---------|-------------|
| Hi / Hello / Hey | Greeting |
| Your name | Shows chatbot name |
| My name | Displays your name |
| How are you | Chatbot response |
| Time | Shows current time |
| Date | Shows today's date |
| Joke | Random programming joke |
| Motivate me | Motivational quote |
| Calc 10+20 | Calculator |
| Help | List all commands |
| Thank you | Bot replies politely |
| Bye | Exit chatbot |
